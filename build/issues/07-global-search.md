# 07 — Global Search

**What to build:** A global search that scans all gardens simultaneously. Accessible from the home screen. Results are grouped by garden and show title + a content snippet with the matching text highlighted. Tapping a result navigates to that note.

**Blocked by:** 02 — GitHub API layer must exist.

- [ ] Search input accessible from garden home screen
- [ ] On query, fetch all notes from all 4 gardens via GitHub API
- [ ] Filter notes by title and body content match
- [ ] Group results by garden
- [ ] Show title + matched content snippet per result
- [ ] Tapping a result navigates to note reading view
- [ ] Loading state while fetching
- [ ] Empty state for no results
