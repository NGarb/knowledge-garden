# 09 — PWA + Mobile Polish

**What to build:** Make the app installable as a PWA on iPhone. Polish all mobile interactions — safe areas, tap targets, scroll behaviour, nav feel — so the app is indistinguishable from a native app in daily use.

**Blocked by:** 05 — core reading flow must be complete before polishing.

- [ ] PWA manifest: name, short_name, icons, display: standalone, background_color, theme_color
- [ ] `apple-mobile-web-app-capable` and related meta tags for iOS
- [ ] Safe area insets respected on all screens (notch, home bar)
- [ ] Minimum 44px tap targets throughout
- [ ] Smooth scroll behaviour on note list and reading view
- [ ] Floating capture button clears the iOS home bar
- [ ] No text selection on UI chrome (only on note body)
- [ ] Confirm installable and functional on iPhone via Safari "Add to Home Screen"
