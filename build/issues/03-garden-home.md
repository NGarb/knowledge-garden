# 03 — Garden Home Screen

**What to build:** The landing screen of the app — 4 garden cards (ai, world, culture, misc). Each card shows the garden name and a note count. Tapping a card navigates to the note list for that garden.

**Blocked by:** 02 — GitHub API layer must exist to fetch note counts.

- [ ] Home screen renders 4 garden cards
- [ ] Each card fetches note count from GitHub API (count of `.md` files in that garden folder)
- [ ] Tapping a card navigates to the garden note list
- [ ] Cards are styled mobile-first, legible at thumb reach
- [ ] Loading and error states handled
